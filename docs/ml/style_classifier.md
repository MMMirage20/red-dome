# Классификатор стиля игрока

Отчёт создан командой `python -m tools.train_style --games 60 --seed 1` (этап 3, ФТ-31).

## Данные

- Партии миссии 3: за игрока — скрипт с заданным стилем (`tools/style_bots.py`), за ВЕКТОРа — «Адаптивный» на правилах.
- По 60 партий на стиль, всего 240; признаки раз в сол с 180 по 300 с партии.
- Деление по партиям: тест — партии с seed % 5 == 0. Строк: обучение 960, тест 240.
- Признаки: `minutes`, `fighters`, `rockets`, `turrets`, `drills`, `refineries`, `solars`, `drones`, `has_reactor`, `hangar_sec`, `reactor_sec`, `attack_sec`, `army_near_base`.

## Ограничения

- Стили играют скрипты, а не люди: на играх тестеров точность нужно перемерить (устав, раздел 4).
- ВЕКТОР видит всю карту (тумана войны в игре пока нет), поэтому признаки — полные, а не разведанные.
